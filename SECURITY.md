# Security

Torden runs inside your DAW and does not use the network, so the attack surface is small. Parsing of project state,
preset files (`.torden`) and user settings is the most relevant part.

If you find a crash or a vulnerability triggered by a crafted file, please do **not** open a public issue. Use
[private vulnerability reporting](https://github.com/fjord-sounds/torden/security/advisories/new) instead.

Only the latest release is supported.
