# Code of Conduct

Be kind and patient. Disagree with ideas, not with people. No harassment, discrimination or personal attacks, in
issues, pull requests, discussions or anywhere else the project is represented.

Maintainers may edit or remove comments and contributions that do not follow this, and may block repeat offenders.
To report a problem, write to the maintainers via a private message to [@NilsHellwig](https://github.com/NilsHellwig).

This is a short version in the spirit of the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
